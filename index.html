About

I'm a software engineer who thinks in products first, code second. Before I write a line, I ask: what problem does this actually solve for the person using it? Architecture Highlights

  • Supervisor agent with conditional re-search logic routes dynamically between nodes based on live graph state, improving result relevance
  • Hybrid RAG pipeline combining pgvector cosine similarity search with PostgreSQL full-text search (tsvector/GIN), merged via reciprocal rank fusion — grounding LLM answers in retrieved postings and reducing hallucinations
